Lexical Rules

Rules derived from the Flex/Lex grammar file TP2.l

🇦 Uppercase Starts

Any word that begins with an uppercase letter (A–Z) followed by any mix of upper and lowercase letters.

[A-Z][A-Za-z]*

🔚 Ends with -er

Any word composed of letters that ends with the suffix er.

[A-Za-z]*er

🇯 Starts with j

Any word beginning with the lowercase letter j followed by any letters.

j[A-Za-z]*
